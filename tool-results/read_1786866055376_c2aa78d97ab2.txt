    48→   647→   647→### ⚠️ Cover Content Overflow Prevention (Mandatory)
    49→   648→   648→
    50→   649→   649→1. Cover section page margin is 0; total content height ≤ 15638 twips (1200 twips safety margin for cross-engine compatibility — MS Office renders large fonts taller than calculated).
    51→   650→   650→2. Color block Table `height` must use `rule: "exact"` (never `"atLeast"`).
    52→   651→   651→3. Each recipe code includes height budget annotations — verify during generation.
    53→   652→   652→4. **`verticalAlign` must always be `"top"`**. Never use `"center"` or `"bottom"` in exact-height rows — content will be clipped or overflow. Use `spacing.before` on the first paragraph for vertical positioning.
    54→   653→   653→5. **Title font size MUST be dynamically calculated via `calcTitleLayout()`** (see below). Never hardcode font sizes above 40pt for cover titles. Every recipe MUST call `calcTitleLayout()` before building title paragraphs.
    55→   654→   654→6. **Never use `margins.top`/`margins.bottom` for vertical positioning inside exact-height cells**: Cell margins reduce available height unpredictably across MS Office and WPS. Use `spacing.before` on the first paragraph instead. Only `margins.left`/`margins.right` are safe.
    56→   655→   655→7. **Dynamic spacing is mandatory**: Use `calcCoverSpacing()` to compute `spacing.before` values dynamically based on content element count and title line count. Never use fixed large spacing values (e.g., `before: 4500`) that assume a specific title length.
    57→   656→   656→8. **Cover must be a single-page section**: The cover section must produce exactly ONE page. If content overflows to a second page, it means the height budget is violated. Common overflow causes and fixes:
    58→   657→   657→   - Title font too large → use `calcTitleLayout()` to auto-reduce
    59→   658→   658→   - Too many meta lines → reduce font size or remove less important lines
    60→   659→   659→   - Fixed `spacing.before` values too large → use `calcCoverSpacing()` for dynamic values
    61→   660→   660→   - Subtitle + English label + meta lines combined exceed budget → calculate total and reduce spacing
    62→   661→   661→9. **Cover wrapper table MUST use explicit `allNoBorders`**: The outer 16838 wrapper table and ALL nested tables inside the cover MUST set borders to NONE explicitly. Never rely on docx-js default borders (`single/auto/sz=4`). Default borders add ~8 twips per edge, which causes MS Office to calculate a total height slightly exceeding 16838 → content overflows to a blank page 2. WPS is more lenient but MS Office is strict. **This is the #1 cause of "blank page 2 in MS Office but not in WPS".**
    63→   662→   662→
    64→   663→   663→```js
    65→   664→   664→// ✅ MANDATORY: Define and use allNoBorders for every cover table
    66→   665→   665→const NB = { style: BorderStyle.NONE, size: 0, color: "FFFFFF" };
    67→   666→   666→const noBorders = { top: NB, bottom: NB, left: NB, right: NB };
    68→   667→   667→const allNoBorders = { top: NB, bottom: NB, left: NB, right: NB,
    69→   668→   668→                       insideHorizontal: NB, insideVertical: NB };
    70→   669→   669→
    71→   670→   670→new Table({
    72→   671→   671→  borders: allNoBorders,  // ← MANDATORY on every cover table
    73→   672→   672→  // ...
    74→   673→   673→});
    75→   674→   674→```
    76→   675→   675→
    77→   676→   676→10. **Decorative lines MUST use paragraph borders, NEVER text characters**: Horizontal decorative lines (accent strips, dividers, frame edges) must be implemented with `paragraph border.top` or `border.bottom` — never with text characters like `───`, `━━━`, `═══`, or `——————`. Character-drawn lines render at inconsistent widths across MS Office and WPS (font metrics differ), causing lines to appear truncated or misaligned. Paragraph borders render pixel-perfect in both engines and their width is controlled precisely via `indent.left` / `indent.right`.
    78→   677→   677→

    80→   679→   679→// ✅ Correct — paragraph border (R2 style thick accent rule)

    83→   682→   682→  border: { top: { style: BorderStyle.SINGLE, size: 18, color: P.accent, space: 20 } },
    84→   683→   683→  children: [],
    85→   684→   684→})
    86→   685→   685→
    87→   686→   686→// ❌ FORBIDDEN — text character line (renders inconsistently)

   119→   718→   718→### ⚠️ Cover Title Layout — calcTitleLayout() (Mandatory for ALL Recipes)
   120→   719→   719→
   121→   720→   720→**Every cover recipe MUST use `calcTitleLayout()` to determine title font size and line breaks.** Hardcoding font sizes or passing the full title as a single TextRun is FORBIDDEN.
   122→   721→   721→
   123→   722→   722→**Every paragraph with font size > body text MUST set explicit line spacing** to prevent top clipping:
   124→   723→   723→```js
   125→   724→   724→// ★ MANDATORY: prevent inherited small line spacing from clipping large fonts
   126→   725→   725→spacing: { line: Math.ceil(titlePt * 23), lineRule: "atLeast", after: 100 }
   127→   726→   726→// Example: 36pt → line: 828; 44pt → line: 1012
   128→   727→   727→```
   129→   728→   728→Without this, the paragraph inherits body text line spacing (e.g., 560tw), which is shorter than the font height → top of characters gets clipped.
   130→   729→   729→
   131→   730→   730→```js
   132→   731→   731→/**
   133→   732→   732→ * Calculate safe font size and smart line breaks for cover titles.
   134→   733→   733→ * MUST be called by every recipe before building title paragraphs.
   135→   734→   734→ *
   136→   735→   735→ * @param {string}  title          Full title string
   137→   736→   736→ * @param {number}  maxWidthTwips  Available width for title text (twips, after subtracting margins/padding)
   138→   737→   737→ * @param {number}  preferredPt    Desired max font size in pt (default 40)
   139→   738→   738→ * @param {number}  minPt          Minimum allowed font size in pt (default 24)
   140→   739→   739→ * @returns {{ titlePt: number, titleLines: string[] }}
   141→   740→   740→ */
   142→   741→   741→function calcTitleLayout(title, maxWidthTwips, preferredPt = 40, minPt = 24) {
   143→   742→   742→  // Each CJK character width ≈ pt × 20 twips
   144→   743→   743→  const charWidth = (pt) => pt * 20;
   145→   744→   744→  const charsPerLine = (pt) => Math.floor(maxWidthTwips / charWidth(pt));
   146→   745→   745→
   147→   746→   746→  // Try from preferredPt downward until title fits in ≤ 3 lines
   148→   747→   747→  let titlePt = preferredPt;
   149→   748→   748→  let lines;
   150→   749→   749→  while (titlePt >= minPt) {
   151→   750→   750→    const cpl = charsPerLine(titlePt);
   152→   751→   751→    if (cpl < 2) { titlePt -= 2; continue; }
   153→   752→   752→    lines = splitTitleLines(title, cpl);
   154→   753→   753→    if (lines.length <= 3) break;
   155→   754→   754→    titlePt -= 2;
   156→   755→   755→  }
   157→   756→   756→
   158→   757→   757→  // If still > 3 lines at minPt, force 3 lines
   159→   758→   758→  if (!lines || lines.length > 3) {
   160→   759→   759→    const cpl = charsPerLine(minPt);
   161→   760→   760→    lines = splitTitleLines(title, cpl);
   162→   761→   761→    titlePt = minPt;
   163→   762→   762→  }
   164→   763→   763→
   165→   764→   764→  return { titlePt, titleLines: lines };
   166→   765→   765→}
   167→   766→   766→
   168→   767→   767→/**
   169→   768→   768→ * Smart Chinese title line-breaking — breaks at semantic boundaries, never mid-word.
   170→   769→   769→ *
   171→   770→   770→ * Rules:
   172→   771→   771→ * 1. Prefer breaking after particles, punctuation, connectors, underscores, spaces
   173→   772→   772→ * 2. Never split a compound word (e.g., "管理规范" must not become "管理规" + "范")
   174→   773→   773→ * 3. No single-character orphan on the last line — merge into previous line
   175→   774→   774→ * 4. If no good break point found within 60-130% of charsPerLine, break at charsPerLine
   176→   775→   775→ *
   177→   776→   776→ * @param {string} title        Full title string
   178→   777→   777→ * @param {number} charsPerLine Max characters per line at current font size
   179→   778→   778→ * @returns {string[]}          Array of line strings
   180→   779→   779→ */
   181→   780→   780→function splitTitleLines(title, charsPerLine) {
   182→   781→   781→  if (title.length <= charsPerLine) return [title];
   183→   782→   782→
   184→   783→   783→  // Characters that are safe break points (break AFTER these)
   185→   784→   784→  const breakAfter = new Set([
   186→   785→   785→    ...'，。、；：！？',              // CJK punctuation
   187→   786→   786→    ...'的与和及之在于为',            // CJK particles/prepositions
   188→   787→   787→    ...'-_—–·/',                     // connectors
   189→   788→   788→    ...' \t',                         // whitespace
   190→   789→   789→  ]);
   191→   790→   790→
   192→   791→   791→  const lines = [];
   193→   792→   792→  let remaining = title;
   194→   793→   793→
   195→   794→   794→  while (remaining.length > charsPerLine) {
   196→   795→   795→    let breakAt = -1;
   197→   796→   796→
   198→   797→   797→    // Search backward from charsPerLine to 60% for a break point
   199→   798→   798→    for (let i = charsPerLine; i >= Math.floor(charsPerLine * 0.6); i--) {
   200→   799→   799→      if (i < remaining.length && breakAfter.has(remaining[i - 1])) {
   201→   800→   800→        breakAt = i;
   202→   801→   801→        break;
   203→   802→   802→      }
   204→   803→   803→    }
   205→   804→   804→
   206→   805→   805→    // If not found, search forward up to 130%
   207→   806→   806→    if (breakAt === -1) {
   208→   807→   807→      const limit = Math.min(remaining.length, Math.ceil(charsPerLine * 1.3));
   209→   808→   808→      for (let i = charsPerLine + 1; i < limit; i++) {
   210→   809→   809→        if (breakAfter.has(remaining[i - 1])) {
   211→   810→   810→          breakAt = i;
   212→   811→   811→          break;
   213→   812→   812→        }
   214→   813→   813→      }
   215→   814→   814→    }
   216→   815→   815→
   217→   816→   816→    // Last resort: break at charsPerLine, but avoid splitting compound CJK words
   218→   817→   817→    if (breakAt === -1) {
   219→   818→   818→      breakAt = charsPerLine;
   220→   819→   819→      // If both chars at the break boundary are CJK (likely a compound word),
   221→   820→   820→      // step back 1 char to keep the word together
   222→   821→   821→      const prevChar = remaining[breakAt - 1];
   223→   822→   822→      const nextChar = remaining[breakAt];
   224→   823→   823→      if (prevChar && nextChar &&
   225→   824→   824→          !breakAfter.has(prevChar) && !breakAfter.has(nextChar) &&
   226→   825→   825→          /[\u4e00-\u9fff]/.test(prevChar) && /[\u4e00-\u9fff]/.test(nextChar)) {
   227→   826→   826→        breakAt = breakAt - 1;
   228→   827→   827→      }
   229→   828→   828→    }
   230→   829→   829→
   231→   830→   830→    lines.push(remaining.slice(0, breakAt).trim());
   232→   831→   831→    remaining = remaining.slice(breakAt).trim();
   233→   832→   832→  }
   234→   833→   833→  if (remaining) lines.push(remaining);
   235→   834→   834→
   236→   835→   835→  // Prevent single-character orphan on last line — merge into previous
   237→   836→   836→  if (lines.length > 1 && lines[lines.length - 1].length <= 2) {
   238→   837→   837→    const last = lines.pop();
   239→   838→   838→    lines[lines.length - 1] += last;
   240→   839→   839→  }
   241→   840→   840→
   242→   841→   841→  return lines;
   243→   842→   842→}
   244→   843→   843→
   245→   844→   844→/**
   246→   845→   845→ * Calculate dynamic spacing values for cover elements to fit within page height.
   247→   846→   846→ *
   248→   847→   847→ * @param {object} params
   249→   848→   848→ * @param {number} params.titleLineCount   Number of title lines
   250→   849→   849→ * @param {number} params.titlePt          Title font size in pt
   251→   850→   850→ * @param {boolean} params.hasSubtitle     Whether subtitle exists
   252→   851→   851→ * @param {boolean} params.hasEnglishLabel Whether English label exists
   253→   852→   852→ * @param {number} params.metaLineCount    Number of meta info lines
   254→   853→   853→ * @param {number} params.fixedHeight      Sum of fixed-height elements (color strips, accent bars, footer) in twips
   255→   854→   854→ * @param {number} params.pageHeight       Total page height in twips (default 16838)
   256→   855→   855→ * @returns {{ topSpacing, midSpacing, bottomSpacing }}  Spacing values in twips
   257→   856→   856→ */
   258→   857→   857→function calcCoverSpacing(params) {
   259→   858→   858→  const {
   260→   859→   859→    titleLineCount = 1, titlePt = 36, hasSubtitle = false,
   261→   860→   860→    hasEnglishLabel = false, metaLineCount = 0,
   262→   861→   861→    fixedHeight = 800, pageHeight = 16838,
   263→   862→   862→    marginTop = 0, marginBottom = 0,   // ★ NEW: pass actual section margins
   264→   863→   863→  } = params;
   265→   864→   864→
   266→   865→   865→  // ★ Safety margin: 1200 twips (cross-engine: MS Office renders large fonts
   267→   866→   866→  // taller than calculated; extra 400tw buffer prevents footer clipping)
   268→   867→   867→  const SAFETY = 1200;
   269→   868→   868→  // ★ Subtract page margins from available height (cover section may have margins)
   270→   869→   869→  const usableHeight = pageHeight - marginTop - marginBottom - SAFETY;
   271→   870→   870→
   272→   871→   871→  // ★ Accurate height estimation per element:
   273→   872→   872→  const titleHeight = titleLineCount * (titlePt * 23 + 200);
   274→   873→   873→  const subtitleHeight = hasSubtitle ? (12 * 23 + 600) : 0;
   275→   874→   874→  const englishLabelHeight = hasEnglishLabel ? (9 * 23 + 600) : 0;
   276→   875→   875→  const metaHeight = metaLineCount * (10 * 23 + 100);
   277→   876→   876→
   278→   877→   877→  // ★ Account for implicit paragraph heights:
   279→   878→   878→  const implicitParaHeight = 3 * 300;
   280→   879→   879→
   281→   880→   880→  const contentHeight = titleHeight + subtitleHeight + englishLabelHeight +
   282→   881→   881→                        metaHeight + fixedHeight + implicitParaHeight;
   283→   882→   882→
   284→   883→   883→  const remainingSpace = usableHeight - contentHeight;
   285→   884→   884→  const safeRemaining = Math.max(remainingSpace, 400);
   286→   885→   885→
   287→   886→   886→  // ★ Footer protection: bottomSpacing must be ≥ FOOTER_MIN to prevent
   288→   887→   887→  // footer + accent line from being clipped at the cell bottom edge
   289→   888→   888→  const FOOTER_MIN = 800;
   290→   889→   889→  const rawTop = Math.floor(safeRemaining * 0.45);
   291→   890→   890→  const rawBottom = Math.floor(safeRemaining * 0.45);
   292→   891→   891→  const bottomSpacing = Math.max(rawBottom, FOOTER_MIN);
   293→   892→   892→  const topSpacing = Math.max(rawTop - Math.max(0, FOOTER_MIN - rawBottom), 400);
   294→   893→   893→  const midSpacing = Math.max(safeRemaining - topSpacing - bottomSpacing, 0);
   295→   894→   894→
   296→   895→   895→  return { topSpacing, midSpacing, bottomSpacing };
   297→   896→   896→}
   298→   897→   897→```

   327→   926→   926→### ⚠️ CRITICAL — Cover Section Non-Negotiables (ALL Recipes)
   328→   927→   927→

   330→   929→   929→
   331→   930→   930→1. **Cover section margin = 0**: The cover MUST be in its own section with `page.margin: { top: 0, bottom: 0, left: 0, right: 0 }`. Non-zero margins shrink the wrapper away from page edges → white gaps around the cover ("cover not filling the page"). This is the #1 cause of broken cover layouts.
   332→   931→   931→
   333→   932→   932→2. **Wrapper row exact height**: The outer wrapper table row MUST set `height: { value: 16838, rule: "exact" }`. Without this, content overflow pushes to page 2, or insufficient content leaves bottom whitespace.
   334→   933→   933→
   335→   934→   934→3. **Wrapper table borders = allNoBorders**: MUST explicitly set `borders: allNoBorders`. Default docx-js borders add ~8 twips per edge. MS Office includes border thickness in exact-height calculation → total exceeds 16838 → blank page 2 (WPS is lenient, MS Office is strict).
